# @furystack/task-runner-examples

Worked examples for the `@furystack/task-runner` primitive.

## Video encoder example

This package includes a video-encoder workflow example built on top of `@furystack/task-runner`.

### Run

From the repository root:

```bash
yarn workspace @furystack/task-runner-examples start
```

This builds/uses the package output as configured by the workspace scripts and starts `./esm/video-encoder/start.js`.
