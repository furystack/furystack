# Domain Docs

This repository is a Yarn workspaces monorepo. Most code lives under `packages/*`, shared docs under `docs/`, and plans under `plans/`.

- **Orientation**: See `CONTEXT-MAP.md` at the repository root for a quick map of key areas.
- **Package docs**: Each package keeps its own `README.md` (and source/tests) in its package directory.
- **Internal docs**: Cross-cutting notes live in `docs/internal/` and migrations in `docs/migrations/`.
- **Vocabulary**: Prefer the terminology used in the relevant package README and source for that area of the codebase.
- **Public user docs**: Framework tutorials and guides live at https://furystack.github.io/getting-started/ (link there from READMEs instead of duplicating long guides).
